# Reporting security or privacy issues

Do not post account information, SavedVariables files, credentials, or private character records in public issues.

For an issue that can be described safely, open a minimal report without sensitive data and ask the maintainer how to provide details privately. No private reporting address is configured in this repository.

IRS Lite keeps records in WoW SavedVariables and does not upload them. The import feature reads the full IRS addon's loaded records only after the user chooses Import and confirms replacement of Lite history.
